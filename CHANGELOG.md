# Changelog

All notable changes to Manipur Singham Last will be documented in this file.

## [1.0.1] - 2024-09-30

### Changed
- Updated package name from `com.altaf.manipursingham` to `com.altaf.manipursinghamlast` for Play Console compliance
- Renamed application class from `KeralaLastApp` to `ManipurSinghamLast`
- Fixed adaptive launcher icon configuration

### Fixed
- Resolved adaptive icon resource linking errors
- Corrected launcher icon resources for better display across different device sizes

## [1.0.0] - 2024-09-XX

### Added
- Initial release of Manipur Singham Last
- First Prize First result display
- First Prize Jodi result display
- Number Combination features
- PDF viewer for result charts
- Home screen with latest results
- Show Result functionality
- Network security configuration for API communication

### Features
- Real-time result updates from manipursingham.com
- PDF viewing capability for detailed result charts
- Paging 3 integration for efficient data loading
- MVVM architecture with Hilt dependency injection
- Material Design UI with navigation components
- Support for multiple time slots including 10:00 PM

### Technical
- Built with Kotlin
- Uses Hilt for dependency injection
- Retrofit for network communication
- Glide for image loading
- Data binding for UI components
- Target SDK 36, Min SDK 24
